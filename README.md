# AnasLab Landing Page

A refreshed, single-page design built from scratch with:

- Smooth scrolling navigation
- Hero layout with image positioned near Senior Engineer Anas
- Responsive cards and contact section
- GitHub Pages deployment workflow

## Run locally

Open `index.html` directly, or serve this folder with any static server.

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. Ensure your default branch is `main` (or `master`).
3. In GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Push a commit; the workflow in `.github/workflows/deploy-pages.yml` will publish the site.
